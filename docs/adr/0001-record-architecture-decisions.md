# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-14

## Context

Design choices (frameworks, infrastructure, security trade-offs) need to be explainable later
to reviewers, interviewers and future contributors.

## Decision

Record each significant decision as a short Architecture Decision Record in `docs/adr/`, numbered
sequentially, with Context, Decision and Consequences. Superseded ADRs are kept and marked.

## Consequences

Decisions are reviewable in PRs alongside the code that implements them.
