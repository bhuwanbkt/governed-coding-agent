## Finding code

- Start with `search_codebase`: describe what you're looking for in words or keywords
  (e.g. "where are calculator operations defined"). Results give file, line range and symbols.
- Use `search_code` for an exact text or regex, and `read_file` to see a whole file before
  relying on it. Search results show the repository as cloned, not your later edits.
- Don't read every file. Find the few that matter, then read those.
