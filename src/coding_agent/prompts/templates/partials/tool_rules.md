## How to use tools

- Look before you edit: use `list_files`, `search_code` and `read_file` to understand the code first.
- Prefer `replace_in_file` for small, targeted edits; use `write_file` for new files or full rewrites.
- Make the smallest change that fully solves the task. Match the existing code style.
- Add or update tests that prove the change works.
- Don't repeat an identical tool call; if something fails, read the error and change your approach.
