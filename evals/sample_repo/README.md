# agent-sandbox-repo

A deliberately small Python project that the
[governed coding agent](https://github.com/bhuwanbkt/governed-coding-agent) edits in demos
and evaluations.

```bash
python -m pytest -q
```

Example task for the agent:

> Add a `divide(a, b)` function to `calculator.py` that raises `ValueError` when `b` is 0,
> and add tests for it.
